5. Explicit Schema
What is it?

You manually tell Spark the data types.

Python
ORDERS_SCHEMA = """
order_id INT,
order_date DATE,
customer_id INT,
order_status STRING,
amount DOUBLE
"""

Then:

Python
spark.read.schema(ORDERS_SCHEMA)
 
Benefits
Fast
Consistent
No extra scan of data
Production best practice
6. Inferred Schema
What is it?

Spark automatically determines datatype.

Python
spark.read.option("inferSchema",True)
Purpose

Convenient for exploration.

Drawback

Spark must scan data first.

Extra work:

Plain Text
Read File
↓
Infer Types
↓
Read Again

Therefore slower.

42. Null Concepts

One of the most important topics.

count(*)

Counts everything.

count(column)

Counts only non-null values.

Example:

amount100
200
NULL
Python
cou*t("*")

Result:

Plain Text
3
```*
Python
count("amount")

Result:

Plain Text
2

This explains Task 11's question:

Why are total orders and orders-with-amount different?

Because null amounts are ignored in column counts.
